# RWA Passport — illustrated atlas

## Selected visual and scope

The user selected the project poster published at https://x.com/derivativador/status/2104908329357062223 on 29 September 2026 and requested the same identity throughout the actual app, including buttons and diagrams. Reference: the project-owned `rwa-passport-cmc-x-moebius.png` output. This update adapts that poster into an interactive research instrument, rather than rendering its screenshot panels as controls.

## Visual language

- Warm ivory paper, deep blue-green ink, washed turquoise, muted gold and lavender in the artwork.
- Georgia system serif for editorial headings and diagram nodes; Inter for data, controls and explanations.
- Fine ruled frames, small paper offsets, restrained corners and Phosphor thin icons.
- Original AI-generated landscape and quiet paper material from the approved poster. Both have adjacent provenance files.
- Live ECharts graph and history palette share `src/lib/atlas-theme.js` with the globe. Selections keep a clearly visible fill and border.

## Working product

The cover leads directly into the geographic explorer, evidence graph and history. Search, current category ranking, production/custody/commercial layers, source links, year controls and numeric tables remain functional. A cover illustration is imaginary geography, not evidence. Actual map boundaries still come from Natural Earth. No market, issuer, custody, history or API semantics were changed for the visual edition.

## Responsive and accessible behavior

Desktop uses an editorial copy/art split. Small screens stack the cover and keep the navigation and search available. The graph keeps its accessible node buttons alongside the horizontally scrollable chart. Keyboard focus is amber, active states use fill plus borders, and reduced-motion preferences remain respected. All decorative raster content is separate from real text and data.

## Release checks

Build and the existing 36 tests are required by AGENTS.md. Browser QA covers the cover CTA, all navigation destinations, search, asset switching, graph node selection, historical years, numeric tables, mobile layout and console errors. Publication retains the existing URL and public audience. A site update does not constitute final event submission.
